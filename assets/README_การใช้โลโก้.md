## 2. โค้ดที่ต้องใส่ใน `<head>` ของทุกหน้า

```html
<link rel="icon" href="assets/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="assets/icon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="assets/icon-180.png">
<meta property="og:image" content="https://PASTE_YOUR_PAGES_URL_HERE/assets/og-image.png">
<meta property="og:title" content="SRDI External Fund 2.0 — ระบบขอรับบริการงบประมาณวิจัยจากแหล่งทุนภายนอก">
<meta property="og:description" content="ยื่นคำขอออกใบเสร็จรับเงิน ติดตามสถานะ และรับสำเนาใบเสร็จทางอีเมล — สถาบันวิจัยและพัฒนาชายแดนภาคใต้ มหาวิทยาลัยราชภัฏยะลา">
```

> `PASTE_YOUR_PAGES_URL_HERE` = โดเมน Cloudflare Pages ของ 2.0 (ยังไม่ตั้ง — รอมติเรื่องชื่อโดเมน)

## 3. สีหลักที่สกัดจากโลโก้จริง (ใช้เป็น design token ของธีม)

| ชื่อ token | ค่า | ที่มา | ใช้ตรงไหน |
|---|---|---|---|
| `--srdi-green` | `#233D00` | สีตัวอักษร SRDI ในโลโก้ (สีที่พบมากที่สุด 8,169 พิกเซล) | สีหลักของแบรนด์ · หัวเว็บ · ปุ่มหลัก |
| `--srdi-pink` | ตัวอักษร `YRU` สีชมพู | ในโลโก้ | สีเน้นเล็ก ๆ เท่านั้น — ห้ามใช้เป็นสีปุ่ม |
| `--srdi-ink` | `#1A1A1A` | ตัวอักษร `X` และบรรทัดคำอธิบาย | ข้อความหลัก |

⚠️ **ยังไม่ใช่ค่าจริงของธีม STAR** — ค่าข้างบนสกัดจากโลโก้เท่านั้น ค่าสีจริงของ `star-results.pages.dev` / `ga-serve.pages.dev` / `srdi-fiscal.pages.dev` **ยังดึงไม่ได้** (Cloudflare Pages ส่ง `index.html` กลับมาแทนไฟล์ `.css`) · ต้องรอคุณสุ่ยแนบไฟล์จาก repo หรือให้ Claude Code ดึงตอนสร้าง — ดูคำถามข้อ 3 ในชุดคำถาม Phase 0

## 4. กติกาการใช้โลโก้ (กันใช้ผิด)

1. **ห้ามยืดบิดสัดส่วน** — ย่อ/ขยายตามอัตราส่วน 435:271 เสมอ
2. **ห้ามเปลี่ยนสีโลโก้** ไม่ว่าจะเป็นโหมดสว่างหรือโหมดมืด — ต้นฉบับพื้นหลังโปร่งใสอยู่แล้ว วางบนพื้นเข้มได้ แต่ถ้าคอนทราสต์ไม่พอในโหมดมืด ให้วางบนแผ่นรองสีขาวโค้งมนแทนการเปลี่ยนสีตัวโลโก้
3. **ความกว้างต่ำสุดบนหน้าจอ 120 px** — เล็กกว่านี้บรรทัดคำอธิบายภาษาอังกฤษจะอ่านไม่ออก ให้ใช้ `icon-*.png` แทน
4. **อีเมลแจ้งเตือน**: ฝังเป็น inline image ผ่าน `MailApp` (`inlineImages`) ไม่ใช่ลิงก์ไป Drive — ลิงก์ Drive จะโดนโปรแกรมอีเมลบล็อกและขึ้นเป็นกรอบว่าง
